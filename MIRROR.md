# @50heads/mcp

This repository is the public publish mirror for the npm package. Each release copies the packed package here, and `.github/workflows/release.yml` publishes that tree to npm with provenance.

The workflow filename `release.yml` is the trusted publisher, with no GitHub environment. Report issues at https://github.com/50heads/mcp/issues.

Do not edit this repository. The next release overwrites it.
